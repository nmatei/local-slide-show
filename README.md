# local-slide-show
Simple web site to use for old devices as slide show

## Live

[nmatei.github.io/local-slide-show/](https://nmatei.github.io/local-slide-show/)

- save the link on your tablet/phone on the home screen and upload the images you want to see

## ⚙ Dev Install

```sh
git clone https://github.com/nmatei/local-slide-show.git
cd local-slide-show
npm install
```

## Usage

```sh
npm start
```

Open http://localhost:3000 to see if it works
